# 趣搭局 · 开放圆桌

基于用户选择的 C 方案整理的矢量版本。圆环、三位参与者与蓝橙配色保留，曲线和间距按几何比例重建。字标采用主题字体配置中的 PingFang SC，已转路径；与 AI 概念图的圆润字形略有差异。

- qudaju-icon：独立标志，透明背景。
- qudaju-logo-vertical：图标在上、名称在下，透明背景。
- qudaju-logo-horizontal：横版组合，透明背景。
- qudaju-icon-mono / white：单色与反白标志。
- qudaju-avatar：白底头像。

各版均提供 SVG 与 1024px 宽 PNG。SVG 可无损缩放，文字不依赖本地字体。色彩来自 src/theme/tokens.json 的 primary、accent、white。

建议标志最小宽度 32px，完整组合最小宽度 120px；保持比例，四周至少留出一个圆点直径的空白。暗背景使用反白版。本轮交付设计文件，未替换应用内资源。

设计流程：SVG Logo Designer，https://skills.sh/rknall/claude-skills/svg-logo-designer 。
