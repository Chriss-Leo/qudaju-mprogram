# 首页四区布局实现

背景使用用户提供的纯摄影图，转换为 493KB JPEG，不重绘人物。
文字、品牌装饰、分类和导航均由代码实现。

## 验证

- vue-tsc 类型检查：通过。
- 微信、支付宝、小红书及 H5 生产构建：通过。
- H5 Playwright：393×852、320×640、1200×900。
- 无横向溢出；分类不被底栏遮挡；本地字体成功加载。
- 陪拍传递关键词进入搜索；发现滚动到活动列表；首页回到顶部。
- 截图：code-iphone.png、code-small.png、code-desktop.png。
- 微信真机安全区、字体与 SVG 尚未实机验证。

## 复现

运行 npm run dev:h5，打开 http://127.0.0.1:5173/。
scripts/check-entry.cjs 依赖 Playwright，可用 QUDADJU_PLAYWRIGHT_PATH
指定本机 Playwright 包路径。

## 限制

背景图片实际 853×1844，不标称原生 2K/4K。
其余页面保留原有演示交易逻辑，未接入后台。
现有项目生产微信输出总量约 12MB，上传发布前仍需处理分包/静态资源，
本次构建成功不等于通过微信发布包大小审核。
