# 首页视觉重构简报

- 范围：`src/pages/index/index.vue` 及其共享导航、服务票券和活动图像组件；Operate 模式。
- 用户任务：快速确认所在区域，搜索或按节目单分类，理解平台保障，发现可预约的本地兴趣服务。
- 批准方向：城市活动海报墙 / B 层叠票券节目单。
- 批准稿：`.impeccable/mocks/home-posterwall-b.png`。
- 记忆点：深绿报头与搜索承接一张主活动票券；内容区以左侧编号节目单控制右侧摄影票券流。
- 约束：保留森林绿、珊瑚橙和暖白；不改变现有筛选、搜索、跳转和跨平台逻辑；所有商业数据仍来自本地示例数据。

## 视觉系统

- 组件语法：纸质活动票券、半圆缺口、虚线撕线、印章与窄信息条；不回退为普通圆角白卡。
- 圆角：主搜索胶囊 999rpx；票券主体 10–18rpx；普通控件 14–22rpx。
- 线条：1–2rpx 深绿或低对比纸张分隔线；票根边界使用虚线。
- 阴影：纸张层叠只使用带垂直偏移的柔和深绿阴影。
- 字阶：报头 64–78rpx，票券标题 34–42rpx，区块标题 32–38rpx，正文 22–26rpx，元数据 19–22rpx。

## 实现清单

| 可见元素 | 构图承诺 | 实现介质 |
| --- | --- | --- |
| 深绿报头 | 品牌与位置同层，主标题和搜索构成首屏入口 | Vue + SCSS |
| 主活动票券 | 摄影占主体，珊瑚票根承载编号和周末提示 | Vue + SCSS + `hero-frisbee.jpg` |
| 城市节目单 | 左侧固定四项编号分类，当前项有明确状态 | Vue + SCSS + 统一 CSS 几何图标 |
| 推荐内容流 | 右侧纵向摄影票券，图文交错并带时间地点条 | Vue + SCSS + 生成摄影资产 |
| 筛选 | 今天/周末/附近为快捷条件，完整筛选仍使用底部抽屉 | 现有状态逻辑 + Vue |
| 底部导航 | 票券切角语言、三个自绘统一图标 | AppTabBar + SCSS |
| 主操作 | 搜索按钮嵌入搜索轨道右侧，深绿实心 | 语义 button |

## 不应照搬

- 生成稿里的具体日期、活动编号和保障措辞只作为演示排版，运行时使用现有真实示例状态。
- 摄影图片不承载文字；所有标题、标签、时间、地点和操作保持语义组件。
- 生成稿的固定侧栏在窄屏下应保持可读，不允许压缩右侧内容到不可操作。
