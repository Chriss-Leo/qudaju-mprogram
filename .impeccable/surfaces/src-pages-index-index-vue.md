# 首页视觉重构简报

- 范围：`src/pages/index/index.vue` 及其共享导航、服务票券和活动图像组件；Operate 模式。
- 用户任务：快速确认所在区域，进入搜索，按横向分类票或距离/时间筛选，发现可预约的本地兴趣服务。
- 批准方向：城市活动海报墙 / B 全幅城市活动海报。
- 实现基线：`src/pages/index/index.vue`，设计合约 `posterwall-b-fullbleed`。
- 记忆点：白色品牌栏承载右上位置胶囊和独立搜索按钮；全幅竖屏纪实摄影上叠左下深绿撕纸大标题与右下珊瑚票根 CTA；四张横向分类票和全幅活动摄影海报流连续展开。
- 约束：保留森林绿、珊瑚橙和暖白；不改变现有筛选、搜索、跳转和跨平台逻辑；所有商业数据仍来自本地示例数据。

## 视觉系统

- 组件语法：全幅摄影海报、深绿撕纸标题、珊瑚票根、横向分类票、半圆票孔、印章与文字贴纸；不回退为普通圆角白卡。
- 圆角：位置胶囊 999rpx；活动海报与纸张 8–12rpx；分类票 4rpx；筛选控件 8–10rpx。
- 线条：1–2rpx 深绿或低对比纸张分隔线；票根边界使用虚线。
- 阴影：主摄影保持贴边无卡片阴影；珊瑚 CTA 与活动摄影海报使用带垂直偏移的柔和阴影。
- 字阶：品牌字标 50rpx，主海报标题 57rpx，活动海报标题 35rpx，分类与筛选 23–25rpx，元数据 16–23rpx。
