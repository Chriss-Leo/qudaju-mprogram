# 趣搭局 · 好搭子，好时光

**同城兴趣组局小程序｜找局、发局、认识同频的人。**

从一场桌游、一段城市漫步，到一次互拍和户外活动，让兴趣成为见面的理由。趣搭局围绕「发现 → 报名 → 参与」设计，保留精简的 **首页 / 发布 / 我的** 三个导航入口，把找局、筛选和报名集中在一条清晰的路径中。

## 产品功能

以少而精的功能串起完整组局体验，适用于同城兴趣活动、桌游社群、城市漫步、摄影互拍与户外搭子等场景。

| 模块 | 产品能力 | 当前状态 |
| --- | --- | --- |
| 发现同城好局 | 独立活动列表、地区选择、关键词搜索、类型/费用/距离/时间/报名方式筛选 | 界面与本地示例筛选已实现；真实定位未接入 |
| 智能推荐附近的局 | 根据距离、兴趣标签、活动时间和剩余名额排序 | 规划中；当前推荐为固定示例顺序 |
| 活动图文卡片 | 发起人头像昵称、1–3张预览图片、时间地点、免费或人均费用、横向堆叠报名头像 | 已实现前端示例与照片预览 |
| 活动详情 | 活动介绍、标签、发起人、报名人数、公开区域、补充照片、报名步骤、固定费用与申请栏 | 已实现前端示例；申请操作不提交报名、不收款 |
| 发布组局 | 朋友圈式文本+图片；桌游、陪拍、向导、户外、交友五类；具体兴趣标签；草稿 | 规划中，发布入口保留 |
| 活动设置 | 活动时间、报名截止、人数、公共区域与集合细节、审核方式、免费/收费及基金用途 | 规划中 |
| 报名与审核 | 报名留言、局主查看个人信息卡片、审核或直接加入、名额控制、退出 | 规划中 |
| 收费与活动基金 | 审核通过后付款、付款成功占正式名额、费用记录、退款与结算 | 规划中，支付与资金业务未接入 |
| 受限聊天 | 局主向本局报名用户发起邀请，对方接受后开启聊天；退出或活动结束后关闭发送 | 规划中，消息与即时通讯未接入 |
| 我的 | 个人简介与兴趣、我报名的、我发起的、收藏、费用记录、消息、客服与设置 | 个人页及入口已实现；对应业务功能待接入 |
| 管理端 | 用户与内容审核、活动与报名管理、标签维护、退款投诉、财务结算 | 规划中，PC后台未实现 |

## 核心机制

- **默认局主审核，可切换直接加入。** 报名时可留一句话，帮助局主了解参与者。
- **免费局与收费局并存。** 收费用于活动基金，说明用途及包含内容；收费审核局在审核通过后付款，付款完成才占正式名额。
- **分层展示地点。** 报名前展示区域或公共场所，审核通过/直接加入成功后按产品规则展示集合细节；收费局付款成功后才占正式名额。
- **聊天有边界。** 只有局主可邀请报名自己活动的用户聊天，对方接受后开启；报名关系失效或活动结束后停止发送，保留历史可读。
- **公开资料保持克制。** 不默认展示电话、微信号、精确住址；举报、拉黑和投诉处理纳入后续业务设计。

以上为目标业务规则，不代表后端已实现。付款超时、退款及基金结算政策仍需结合具体运营方案确认。

## 技术与定制方向

**uni-app + Vue 3 + TypeScript + Vite**，微信小程序优先；保留支付宝、小红书平台适配目录。其他平台的正式发布与兼容性需另行验证。

- 配色、字体、字阶、字重、行高与通用圆角统一管理，便于品牌换肤。
- 图文网格、报名头像堆叠、安全区头部和底部导航采用共享组件。
- 支持 H5 界面预览，方便需求评审与迭代。
- 可沟通品牌视觉、活动分类与标签、报名规则、业务接口、管理端及多平台适配等定制需求；交付范围以双方确认的方案为准。
