## 报名与聊天本地流程（2026-10-14）

`src/stores/meetups.ts` 使用固定示例身份 `me`、自有示例活动 `my-game` 和虚构成员，以 uni 本地存储持久化响应式状态。刷新后可继续体验；没有跨用户、跨设备同步。

- 报名留言、待审核/待付款/已报名/活动中/已结束/已退出等状态与筛选已实现。免费直接加入或免费审核通过后占名额；待审核和待付款不占正式名额。
- 待付款卡片提供明确的「本地付款流程体验」确认框，不收款；仅模拟完成后转为已报名，并检查名额上限。收费正式报名的退出被拦截，退款规则与接口尚未接入。
- 自有活动可查看成员、通过/拒绝申请、向有效报名成员发起聊天邀请、结束活动。所有权和报名关系检查仅在客户端本地执行，不能替代服务端授权或并发名额控制。
- 邀请仅待回应且收件人匹配时可接受/拒绝；接受后可发送本地文字消息。退出或活动结束后冻结相关邀请/会话的关闭状态，已接受会话的历史记录保留可读；重新报名不会复活旧邀请或旧会话，需新邀请。未接受邀请不能查看或发送聊天内容。
- 消息页的聊天/通知/邀请分栏、邀请读取与未读标记已实现；通知仅为本地报名流程提示，没有 IM、推送或真实通知后台。

验证记录：本地状态与浏览器交互检查通过；320、393、1200px 的成员、邀请、消息、聊天/关闭历史、报名、发起与申请页面截图在 `local-tests/flows-20261014/`。`npm run type-check`、微信小程序与 H5 构建通过；截图和编译不等于真机、真实支付或生产业务验收。原生键盘、胶囊与安全区仍需目标平台真机检查。

独立完成复核：本地功能原型范围PASS。已修复退出后重新报名复活旧会话的问题；旧邀请永久冻结，重新报名需新邀请。已修复报名与成员邀请输入框宽度，在320/393/1200px均受容器约束。`store-check.cjs`、`browser-check.mjs`与`fix-check.mjs`保留状态与实际UI操作回归证据；最后一项覆盖接受、发送、退出、重报、旧聊天只读及刷新保持。
